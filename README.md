# Shadows of Doubt Co-op: updates

This repo is the update channel for the Shadows of Doubt co-op mod. The mod checks
`updates/latest.json` when the game starts and, when there's a newer version, downloads that
version's `SoDCoop.dll`, checks it against the SHA-256 listed here, and puts it in place the next
time the game starts. Older versions stay on your PC (the installer's "Versions..." window).

To get the mod, ask the person who sent you the installer.
